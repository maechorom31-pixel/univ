# 파서 표본 — 지어낸 자료입니다

대교협 파일의 **두 가지 모양**을 각각 몇 줄만 흉내 낸 것입니다.
`board/parse.test.mjs` 가 돌 때마다 둘 다 읽어서, 한쪽을 고치다 다른 쪽이 깨지는
것을 잡습니다.

| 파일 | 모양 |
|---|---|
| `즐겨찾기-옛모양.json` | 1행 머리글 · 2행 내신/수능 아래 머리글 · 3행부터 자료. 결과 칸 있음 |
| `관심대학-새모양.json` | 2행 제목 · **4행 머리글** · 5행부터 자료. 결과 칸 없고 최저가 Y/N |

**이름과 성적은 전부 지어낸 것입니다.** 실제 시트는 학생 실명이 들어 있어
저장소에 넣지 않습니다. 실제 파일로 확인하실 때는 스크래치 폴더에 두고 경로로
넘기세요.

```
node board/parse.test.mjs                       # 지어낸 두 벌
node board/parse.test.mjs /어딘가/진짜시트.json    # 여기에 더해서
```

엑셀을 2차원 배열 JSON 으로 뽑는 것은 구글 시트에서
`=ARRAYFORMULA(...)` 없이도 됩니다 — Apps Script 편집기에서
`sourceSheet_().getDataRange().getValues()` 를 `Logger.log(JSON.stringify(...))` 로
찍으면 그대로 나옵니다.

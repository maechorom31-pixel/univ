# 수시입결검색기 (2022~2026)

대학이 공개한 수시 입시결과를 보기 쉽게 정리한 검색·분석 도구입니다.
**만든이: 나주고 3학년실**

## 사용법

- `index.html` 파일 하나로 동작합니다. (데이터가 파일 안에 모두 내장되어 있음)
- 브라우저에서 바로 열어 사용하거나, 링크로 공유할 수 있습니다.
- 차트 표시를 위해 인터넷 연결이 필요합니다. (Chart.js CDN)

## 주요 기능

- 지역 · 계열 · 전형 카테고리 · 연도 · 대학명 · 학과 키워드로 필터링
- **등급 필터(선택형)**: 기본은 전체 표시, "등급 적용"을 켜면 내 등급대만 추려서 보기
- **선택한 조건 + 내 등급 기준 추천 대학·학과** (사이드바에서 고른 필터를 그대로 반영)
- 카드 / 산점도 / 5년 추이 / 표 4가지 보기
- **산점도 동적 축**: X·Y축을 등급70/등급50/경쟁률/모집인원/지원인원/연도 중 자유 선택, 범위 자동 맞춤
- 학과 클릭 시 전형별 5년 추이 모달
- **모바일 대응**: 폰에서 필터는 ☰ 드로어, 표는 가로 스크롤, 모달은 바텀시트
- **검색조건 링크 공유**: 🔗 링크 복사 버튼으로 현재 필터·등급 조건을 URL에 담아 그대로 전달
- 데이터는 **대학 공개자료 기준**

2. **Source**: `Deploy from a branch`
3. **Branch**: `claude/busy-bohr-akL3s` · 폴더 `/ (root)` → **Save**
4. 잠시 후 아래 주소로 공개됩니다 (이후 이 브랜치에 푸시하면 자동 갱신):


## 통합 입결 데이터 (`data/`)

`index.html`에 내장된 데이터와 대학어디가 발표자료 엑셀을 합쳐 만든 정제 데이터입니다.
**아직 두 페이지에 연결하지 않았습니다.** 필요할 때 불러 쓰면 됩니다.

| 파일 | 내용 |
|---|---|
| `ipgyeol.json` | 통합 입결 75,494행 (2022~2026 수시) |
| `track_alias.json` | 전형명 별칭표 484건 (사이트 표기 → 정본 표기) |
| `review_track_conflict.csv` | 전형명 통일 시 키가 겹치는 234행 — 육안 확인용 |
| `review_comp_anomaly.csv` | 경쟁률 1 미만 502행, 그중 시간서식 오파싱 의심 16행 |

### 왜 만들었나

전형명 표기가 연도마다 달라(`교과(지역)` ↔ `교과(지역균형)`, `잠재능력(면접)` ↔
`종합(잠재능력-면접)`) 같은 전형인데도 연도가 이어지지 않았습니다. 엑셀 쪽은 표기가
전 연도에 통일돼 있어 이를 정본으로 삼고, 겹치는 행에서 대응을 학습해 2022년과
엑셀에 없는 행에도 소급 적용했습니다.

- 전년 대비 비교 가능한 학과·전형: **13.5% → 66.0%**
- 전년 비교가 하나도 안 되던 대학 66곳 중 **64곳 해소** (경북대 0→270, 서울대 0→121)
- 2025학년도 행 12,792 → 15,664

### 같이 잡은 것

- **등급50/70 역전 1,634건** — 70%컷은 50%컷보다 나쁜 값이어야 하는데 엑셀 원본에
  역전이 있었습니다(조선대 213, 경상국립대 172). 두 값을 맞바꿔 정렬했습니다.
- **경쟁률 시간서식 오파싱** — `0.375694`처럼 `9:01`로 읽힌 값이 있습니다. 다만
  경쟁률 1 미만은 실제 미달인 경우가 더 많아, 엑셀에 대조 근거가 있는 것만 되돌리고
  나머지 16행은 `review_comp_anomaly.csv`에 남겨 두었습니다.

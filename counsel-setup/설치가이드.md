# 내신 중심 진학상담 보드 — 설치 가이드 (약 10분)

## 0. 구성 개요
- **counsel.html** — 상담 화면. 학생 정보가 내장되지 않으며, 열 때마다 선생님 구글시트에서 실시간으로 불러옵니다.
- **구글시트 1개** — 모든 데이터 저장소. 시트를 수정하면 🔄 새로고침 시 바로 반영됩니다.

## 1. 구글시트 만들기
새 스프레드시트를 만들고 아래 **탭 이름 그대로** 생성합니다.

| 탭 이름 | 내용 | 채우는 방법 |
|---|---|---|
| `학과입결` | 5년 입결 (72,770행) | `학과입결.csv` → 파일·가져오기·**현재 시트에 붙이기** |
| `최저타깃` | 타깃 학과 수능최저 23~26 | `최저타깃.csv` 가져온 뒤 직접 행 추가 |
| `내신1반` ~ `내신6반` | 나이스 원본 | 나이스 「교과학습발달상황」 엑셀을 열어 **그대로 복사·붙여넣기** (학기 추가 시 아래에 이어붙임) |
| `모고` | 모의고사 성적 | 기존 모고 트래커 시트의 데이터 탭을 복사 |
| `상담` | 상담 기록 | 비워두면 자동 생성 (도구에서 저장) |

> 입결 CSV가 커서 가져오기에 1~2분 걸릴 수 있습니다.

## 2. Apps Script 배포
1. 시트에서 **확장 프로그램 → Apps Script**
2. `Code.gs` 내용 전체를 붙여넣고 저장
3. **배포 → 새 배포 → 유형: 웹 앱**
   - 실행: **나**
   - 액세스 권한: **모든 사용자** (익명 호출 허용 — URL을 아는 사람만 접근 가능하므로 URL을 공유하지 마세요)
4. 생성된 `https://script.google.com/macros/s/…/exec` URL 복사

## 3. counsel.html 연결
1. `counsel.html`을 브라우저로 열기 (또는 GitHub Pages 주소)
2. 우상단 **⚙️ 설정** → Apps Script URL 붙여넣기 → **저장 후 연결**
3. 상단 칩이 "전체 연결됨"이 되면 완료

## 4. 사용 흐름
- **학생 탭**: 반 선택 → 학생 클릭 → 내신 성적표·추이·내신×모고·희망학과 포트폴리오
- **학과 탭**: 검색 → 전형별 5년 추이 + 27예측밴드 + 최저 4년 + 희망 학생 (학생 선택 상태면 그 학생 기준 판정·내신선 오버레이)
- **희망학과 추가/메모**: 학생 탭에서 검색·클릭 → 시트 `상담` 탭에 누적 저장
- **수정 반영**: 입결 오류·27 변동 등은 시트에서 직접 수정 → 도구 🔄
- **📖 분석 안내**: 모든 통계 기법의 식·검증 근거·한계 설명

## 5. 개인정보
학생 성적·이름·메모는 **선생님 구글 계정의 시트에만** 존재합니다. counsel.html 파일·저장소에는 어떤 학생 정보도 포함되지 않습니다.

## 문제 해결
- "연결 실패" → 배포 시 액세스 권한이 '모든 사용자'인지 확인, 재배포 시 **새 배포**(URL이 바뀜)
- 학생이 안 보임 → 내신N반 탭 이름 확인, 나이스 붙여넣기에 헤더(번호/성명…)가 포함됐는지 확인
- 모고 연결 안 됨 → 모고 탭에 4자리 학번(3101 형식) 열이 있는지 확인

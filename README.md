# 수시입결검색기 (2022~2026)

대학이 공개한 수시 입시결과를 보기 쉽게 정리한 검색·분석 도구입니다.
**만든이: 나주고**

## 사용법

- `index.html` 파일 하나로 동작합니다. (데이터가 파일 안에 모두 내장되어 있음)
- 브라우저에서 바로 열어 사용하거나, 링크로 공유할 수 있습니다.
- 차트 표시를 위해 인터넷 연결이 필요합니다. (Chart.js CDN)

## 주요 기능

- 지역 · 계열 · 전형 카테고리 · 연도 · 대학명 · 학과 키워드로 필터링
- **등급 필터(선택형)**: 기본은 전체 표시, "등급 적용"을 켜면 내 등급대만 추려서 보기
- **선택한 조건 + 내 등급 기준 추천 대학·학과** (사이드바에서 고른 필터를 그대로 반영)
- 카드 / 산점도 / 5년 추이 / 표 4가지 보기
- **산점도 동적 축**: X·Y축을 등급70/등급50/경쟁률/모집인원/지원인원/연도 중 자유 선택, 범위 자동 맞춤
- 학과 클릭 시 전형별 5년 추이 모달
- **모바일 대응**: 폰에서 필터는 ☰ 드로어, 표는 가로 스크롤, 모달은 바텀시트

## 온라인 공유 (GitHub Pages)

이 저장소는 `index.html` 하나로 동작하므로 Pages만 켜면 바로 공유 링크가 생깁니다.

1. 저장소 → **Settings** → 좌측 **Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: `claude/busy-bohr-akL3s` · 폴더 `/ (root)` → **Save**
4. 잠시 후 아래 주소로 공개됩니다 (이후 이 브랜치에 푸시하면 자동 갱신):

```
https://maechorom31-pixel.github.io/univ/
```

# 수시 경쟁률 통합 — 쓰는 법과 자료 수집 방침

## 배포 주소

https://maechorom31-pixel.github.io/univ/ratio.html

브랜치에 `ratio.html`을 푸시하면 1~2분 뒤 갱신됩니다.

## 선생님 PC에서 한 번에 돌리기

윈도우는 저장소 폴더의 `경쟁률수집.bat`을 더블클릭합니다.
맥은 터미널에서 `sh 경쟁률수집.command`.

네 단계를 이어서 합니다: 수집 → 화면 만들기 → 내년용 자료로 접기 → 저장소에 올리기.

올리기는 폴더가 git 저장소면 git으로, ZIP으로 내려받은 폴더면
`scripts/ratio_upload.py`가 GitHub 토큰으로 직접 올립니다. 토큰은 처음 한 번만
묻고 사용자 홈 폴더의 `.univ_token`에 둡니다(저장소 폴더 밖이라 함께 올라가지
않습니다). 토큰을 채팅이나 코드에 적지 마세요.

토큰 만들기: github.com → 프로필 → Settings → Developer settings →
Personal access tokens → Fine-grained tokens → Generate new token.
Repository access 에서 `univ` 저장소만 고르고, Permissions → Contents 를
Read and write 로 두면 됩니다. 만료는 90일 정도로.

올리지 못해도 화면 파일은 정상이라 그대로 열립니다.

## 명령으로 돌리기

    python scripts/ratio_fetch.py       # 지금 시각 기준으로 수집 -> data/ratio/snap-*.json
    python scripts/ratio_build.py       # 스냅샷 + 과거 자료 -> ratio.html
    python scripts/ratio_archive.py     # 올해 스냅샷 전부 -> data/ratio_hist_2027.json

`ratio.html`을 브라우저로 열면 끝입니다. 인터넷 연결 없이도 열립니다.

## 언제 돌려 두면 좋은지

내년 예측의 재료가 되는 건 **마감 사흘 전부터 마감 시각까지의 스냅샷**입니다.
과거 자료가 다섯 구간(3일 전·2일 전·1일 전·마감일 오전·마감일 오후)뿐이라,
올해는 그보다 촘촘히 남겨 두면 내년에는 시각 단위 예측이 가능해집니다.

권하는 간격:

| 시기 | 간격 |
|---|---|
| 마감 3일 전 ~ 2일 전 | 하루 두 번(오전·오후) |
| 마감 1일 전 | 두 시간마다 |
| 마감일 | 한 시간마다, 마감 두 시간 전부터는 30분마다 |
| 마감 뒤 | 「최종」이 뜬 뒤 한 번 더 |

윈도우 작업 스케줄러에 등록하면 손대지 않아도 됩니다. 관리자 권한 명령 프롬프트에서
(저장소 폴더 경로는 본인 것으로):

    schtasks /create /tn 경쟁률수집 /sc hourly /mo 1 /st 09:00 /tr "C:\경로\univ\경쟁률수집.bat" /f

마감이 지나면 `schtasks /delete /tn 경쟁률수집 /f`로 지웁니다.
직전 대비 증가(+숫자)는 한 시간 넘게 앞선 스냅샷과 비교하므로, 몇 분 간격으로
여러 번 돌려도 비교 대상이 흐트러지지 않습니다.

## 자동으로 올리기 — GitHub Actions

`.github/workflows/ratio.yml`이 유웨이 대학을 클라우드에서 스스로 수집해 올립니다.
Actions 탭에서 「ratio」→「Run workflow」를 누르면 바로 한 번 돌고, 접수 기간
(9월 7~11일) 한국 시각 9~21시 매시 정각에 스스로 돕니다.

다만 일정(schedule)은 **저장소의 기본 브랜치**에서만 돕니다. 지금 기본 브랜치는
`claude/busy-bohr-akL3s`라 이 브랜치에서는 손수 누를 때만 돕니다. 저장소 설정
→ Branches 에서 기본 브랜치를 이 브랜치로 바꾸면 일정대로 돕니다.

정리하면 자료가 들어오는 길은 셋입니다. 셋 다 결과는 같은 스냅샷 파일이라
섞여도 됩니다.

| 길 | 되는 대학 | 손 |
|---|---|---|
| 선생님 PC에서 `경쟁률수집.bat` | 유웨이 + 진학어플라이 | 더블클릭 (올리기까지) |
| GitHub Actions | 유웨이만 | 없음 |
| 채팅(Claude)에서 명령 실행 | 유웨이만 | 요청할 때마다 |

세 번째 길은 앞의 둘이 안 될 때의 예비로만 두시면 됩니다. 자료 작업을 채팅에서
이어 갈 필요는 없습니다.

## 진학어플라이

`addon.jinhakapply.com`은 데이터센터 IP를 막고 있어 클라우드에서는 403이 납니다.
개인 PC·학교망에서 같은 명령을 돌리면 함께 수집됩니다. 실패한 곳은 건너뛰고
화면의 「대학별 기준시각」 탭 아래에 목록으로 남습니다. GitHub Actions나
Apps Script로 자동화해도 같은 이유로 막히니, 진학어플라이 대학은 PC에서 돌리는
것이 유일한 길입니다.

## 자료 출처

- `data/ratio_hist.json` — 이투스 「2027 수시 실시간 경쟁률 검색기」(xlsb)의
  2026·2025·2024학년도 시점별 경쟁률(3일 전 ~ 최종). 배율 통계와 「2026 동시점」이
  여기서 나옵니다. 186개 대학, 18,621행. `scripts/build_ratio_hist.py <파일.xlsb>`로
  다시 만듭니다(`pip install pyxlsb`). xlsb 원본(19MB)은 저장소에 넣지 않습니다.
  내년에 새 파일을 받으면 같은 명령으로 갈아 끼우면 되고, 화면의 연도 표기는
  자료의 학년도를 따라 스스로 바뀝니다.
- `data/mojip2027.json` — 2026·2025·2024학년도 최종 경쟁률. 「작년 최종」과
  「진도율」이 여기서 나옵니다.
- `data/ratio/snap-*.json` — 올해 수집한 스냅샷. 저장소에 함께 올립니다.
- `data/ratio_hist_2027.json` — 올해 스냅샷을 위 이투스 자료와 같은 꼴로 접은 것.
  `ratio_archive.py`가 언제든 다시 만들므로 저장소에는 올리지 않습니다.
  내년 화면은 `data/ratio_hist*.json`을 모두 읽으니 이 파일만 두면 2027학년도가
  예측 자료에 더해집니다.

## 예측이 어떻게 나오고 얼마나 맞는지

배율 = 최종 경쟁률 ÷ 같은 시점 경쟁률. 과거 3개년에서 이 배율을 모아 지금
경쟁률에 곱합니다. 두 갈래를 기하평균으로 합칩니다.

- **자리 배율**: 같은 모집단위 → 같은 대학·전형 → 같은 대학·유형 → 전형유형
  순으로 표본이 넉넉한 단계의 중앙값. 그 전형만의 막판 흐름을 압니다.
- **구간 배율**: 같은 시점에 경쟁률이 비슷했던 곳들(1 미만 · 1~2 · 2~3 · 3~5 ·
  5~10 · 10 이상)의 중앙값. 같은 대학 표본이 15개 이상이면 그 대학 것, 아니면
  같은 전형유형 것, 그것도 30개가 안 되면 전체 것.

구간 배율을 넣은 이유: 지금 낮은 곳일수록 막판에 크게 뜁니다. 마감 1일 전에
1:1 미만이던 곳은 최종까지 중앙값 3.0배, 10:1 넘던 곳은 1.65배였습니다.
자리 배율만 쓰면 낮은 곳의 최종을 4할 가까이 낮게 보고(예측÷실제 중앙 0.58),
상담에서 제일 중요한 「이 학과 정말 미달로 끝나나」를 계속 틀리게 됩니다.

빌드 때마다 자료의 앞선 두 해(2024·2025) 배율로 마지막 해(2026) 최종을 맞혀 보고
그 결과를 화면 아래 「이 예측이 얼마나 맞는지」 표에 그대로 적습니다. 현재 값:

| 시점 | 중앙 오차 | 80% 구간 적중 |
|---|---|---|
| 3일 전 | 25% | 81% |
| 2일 전 | 21% | 79% |
| 1일 전 | 15% | 80% |
| 마감일 오전 | 8% | 79% |
| 마감일 오후 | 6% | 75% |

「최종 2:1 미만」 확률은 배율을 옮기지 않은 구간 표본에서 곧바로 셉니다
(같은 시점에 경쟁률이 비슷했던 곳 중 실제로 2:1 미만으로 끝난 비율).
역검증에서 70%대로 적힌 곳은 실제 58~69%, 90%대는 80~87%가 그렇게 끝났습니다.
조금 부풀려 보이니 90% 이상만 「거의 확실」로 읽는 편이 안전합니다.

## 70%컷 · 내 등급 · 상담 추천순

`data/ipgyeol.json`의 가장 최근 해 70%컷을 모집단위마다 붙입니다. 전형이 맞으면
그 값, 아니면 같은 유형(교과/종합)의 중앙값을 회색으로 보입니다. 화면의
「내 등급」은 메모리에만 있고 저장하지 않으며, 새로 고치면 지워집니다.
학생 이름을 넣을 곳은 없습니다.

「상담 추천순」은 최종 2:1 미만 확률 45 · 예측 최종 20 · 진도율 15 · 2025 동시점
대비 10 · 근거의 두께 10으로 100점을 만들고, 등급을 알면 닿지 않는 곳(컷보다
0.3등급 넘게 모자람)을 40점 내리고 여유를 15점까지 보탭니다. 이 정렬을 고르면
행마다 근거가 적힙니다.

## 알려진 한계

- 작년 시점별 자료에 없는 전형(농어촌·사회배려·기회균형·실기 세부종목 등)은
  「2026 동시점」이 비고, 예측은 대학·유형 이상의 넓은 배율로 나옵니다.
  9월 10일 18시 수집(33개 대학)에서는 모집단위의 4할가량이 그렇습니다. 대부분 정원외·특기자·타 캠퍼스입니다.
- 마감 시각은 대학 페이지 공지에서 읽습니다. 공지가 없거나 작년 문구가 남아
  있으면(2026년 원광대가 그랬습니다) 다른 대학들의 마감일로 대신하고
  「대학별 기준시각」 탭 비고에 사유를 적습니다.
- 페이지가 「최종」이라 적어야 최종으로 봅니다. 공지문의 「최종 경쟁률은 …
  이후 공지」 같은 문구는 최종으로 치지 않습니다.

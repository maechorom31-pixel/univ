## 1. 수시입결검색기 (`index.html`) — 2022~2026

지난 5년 입시결과로 **합격선의 흐름**을 보는 회고형 도구입니다.

- 지역 · 계열 · 전형 카테고리 · 연도 · 대학명 · 학과 키워드로 필터링
- **등급 필터(선택형)**: 기본은 전체 표시, "등급 적용"을 켜면 내 등급대만 추려서 보기
- **선택한 조건 + 내 등급 기준 추천 대학·학과**
- 카드 / 산점도 / 5년 추이 / 표 4가지 보기
- **산점도 동적 축**: 등급70/등급50/경쟁률/모집인원/지원인원/연도 중 자유 선택
- 학과 클릭 시 전형별 5년 추이 모달, 전형별 통계 요약(Δ전년·추세·변동폭)

## 2. 2027 수시 전형설계 검색기 (`planner.html`) — 신규

2027학년도 모집요강으로 **올해 지원 전략을 짜는** 전방형 도구입니다.
223개 대학 16,873개 모집단위를 담고 있습니다.

### 왜 따로 만들었나

`index.html`이 "작년까지 어땠나"를 본다면, 이 도구는 "올해 어디에 어떻게 넣을까"를 봅니다.
모집요강 자료에만 있는 **추가합격 인원 · 대학별고사 일정 · 전형방법 · 수능최저 · 지원자격**을 활용합니다.

### 핵심 기능 두 가지

**① 실질경쟁률** — 명목경쟁률은 실제 난이도를 크게 왜곡합니다.

```
실질경쟁률 = 명목경쟁률 × 모집인원 ÷ (모집인원 + 추가합격인원)
충원율     = 추가합격인원 ÷ 모집인원 × 100
```

전체 중앙값이 **명목 7.71:1 → 실질 3.47:1**로 내려갑니다.
평균 충원율은 128%이고, 절반이 넘는 모집단위에서 모집인원보다 많은 인원이 추가합격했습니다.

**② 대학별고사 일정 충돌 검사** — 관심 전형을 담으면 면접·논술 날짜가 겹치는지 자동으로 검사합니다.

- **⚠ 확정 충돌**: 서로 다른 대학이 단일 일자로 공지한 고사가 같은 날 → 둘 다 응시 불가
- **△ 확인 필요**: 한쪽이 기간 공지(예: 11.25~11.27)이거나 같은 대학 안에서 겹침 → 대학 공지 확인 필요

### 그 밖의 기능

- 조건 칩 필터: **최저없음 · 면접없음 · 논술전형 · 재수생 가능 · 2027 신설 · 인원 증가 · 실질경쟁률 3:1 이하**
- 카드에 명목/실질 경쟁률 병기, 70%컷 3개년 스파크라인, 2027 모집인원 전년 대비 증감
- 표(12열 정렬) · 산점도(축 6종 자유 선택) · 상세 모달
- 상세 모달: 3개년 경쟁률·입결·추합, 모집인원 4개년, 단계별 전형방법, 일정, 수능최저 전문, 학생부 반영 방식, 지원자격 전문
- **🗂 지원 플래너**: 담은 전형이 브라우저에 저장되고, 수시 6회 초과 시 경고, 수능전/후 타임라인, 링크 공유
- **과거 입결 상호연결**: 상세 모달에서 그 학과의 2022~2026 등급 70%컷을 바로 보고, 수시입결검색기로 건너뛸 수 있습니다. 반대로 입결검색기 모달에서도 2027 모집요강으로 넘어옵니다.

### 두 도구 사이 오가기

같은 학과인데 두 자료의 이름 표기가 달라(`국립공주대`/`공주대`, `고려대(세)`/`고려대(세종)`, `서울과기대`/`서울과학기술대`) 그대로는 이어지지 않습니다.
양쪽 이름을 같은 규칙으로 정규화해 **16,873개 모집단위 중 14,780개(87.6%)**를 과거 입결과 연결했습니다.

이름만으로 잇다 보면 서로 다른 학과가 한데 묶일 위험이 있습니다. 예를 들어 괄호를 모두 지우면 `한의예과(인문)`과 `한의예과(자연)`이 같은 학과가 되어 엉뚱한 입결이 붙습니다.
그래서 **계열·야간·남녀·수업연한을 가르는 괄호는 지우지 않고 키에 남깁니다.** 애매하면 잇지 않고 비워 두는 쪽을 택했습니다 — 링크가 없는 편이 잘못된 링크보다 낫기 때문입니다.

연결표는 `scripts/build_xref.py`가 만듭니다. `index.html`의 자료가 갱신되면 다시 실행하세요.

```bash
python3 scripts/build_xref.py       # index.html + mojip2027.json → data/xref.json
python3 scripts/build_planner.py    # 다시 빌드
```

### 자료를 다루는 원칙

숫자로 보이지만 계산에 넣으면 안 되는 값들을 걸러냅니다.

- **환산점수 기준 입결**은 등급(1~9)이 아니므로 등급 축·등급 필터에서 제외
- **`모집인원 + 추가합격`이 지원자 수보다 많은 332건**은 추가합격이 누적 예비번호로 기재된 것으로 보여, 실질경쟁률을 계산하지 않고 상세에서 `자료 불일치`로 표시
- **`2027 신설` · `2025 통합 모집`** 표기는 결측이 아니라 정보이므로 배지·안내로 노출
- 미달 학과(명목경쟁률 < 1)는 추가합격 개념이 성립하지 않으므로 명목값을 그대로 사용

자세한 검증 내역은 [`PLAN_2027.md`](PLAN_2027.md)에 있습니다.

### 데이터 갱신

`planner.html`은 엑셀 원본에서 자동 생성됩니다. 모집요강이 갱신되면 두 명령만 다시 실행하면 됩니다.

```bash
python3 scripts/parse_2027.py <2027모집요강_엑셀경로> data/mojip2027.json
python3 scripts/build_xref.py
python3 scripts/build_planner.py
```

| 파일 | 역할 |
|---|---|
| `src/planner.tpl.html` | 화면·로직 원본 |
| `scripts/parse_2027.py` | 엑셀 → 정제 JSON (중복·오타·텍스트 혼입 정리) |
| `scripts/build_xref.py` | `index.html` ↔ 모집요강 학과 연결표 |
| `scripts/build_planner.py` | 템플릿 + JSON → `planner.html` |
| `data/mojip2027.json` | 정제 데이터 (16,873행) |
| `data/xref.json` | 과거 입결 연결표 (4,999개 학과) |

- 차트(산점도·추이 그래프)를 그릴 때만 인터넷 연결이 필요합니다. (Chart.js CDN)

  차트 라이브러리는 화면을 다 그린 뒤 따로 받아오므로, 막힌 망에서도 0.7초 안에 사용할 수 있습니다.
- **모바일 대응**: 폰에서 필터는 ☰ 드로어, 표는 가로 스크롤, 모달은 바텀시트
- **링크 공유**: 🔗 버튼으로 현재 검색조건(플래너는 담은 목록까지)을 URL에 담아 그대로 전달
- 모든 수치는 대학 공개자료 및 모집요강 요약본 기준의 **참고값**입니다.
  실질경쟁률·충원율은 공개된 추가합격 인원으로 계산한 값이며 대학이 공식 발표한 수치가 아닙니다.
  **최종 모집요강과 대학 공식 발표 자료를 반드시 확인하세요.**

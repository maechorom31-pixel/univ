# 수시 상담 보드 — 설치

한 번만 하면 됩니다. 20분쯤 걸립니다.

> **먼저 알아 두실 것**
> 학생 이름·성적은 **선생님 구글시트 안에만** 있습니다. GitHub 에는 올라가지 않습니다.
> 잠금은 **배포 주소를 공유하지 않는 것**입니다. 주소를 아는 사람은 들어옵니다.
> 그래서 이 주소는 3학년실 안에서만 나눠 주세요.

---

## 1. 즐겨찾기 엑셀을 시트로 올리기

1. 대교협(어디가)에서 **즐겨찾기 → 엑셀 내려받기**
2. 구글 드라이브에 올리고 **구글 시트로 열기** (파일 → 구글 스프레드시트로 저장)
3. 그 시트 안에서 원본이 든 탭 이름을 확인합니다.
   `다운로드 원본` · `원본` · `즐겨찾기` 중 하나면 그대로 두시면 됩니다.
   다르면 이름을 셋 중 하나로 바꿔 주세요.

원본 탭은 **손대지 마세요.** 보드가 읽기만 합니다. 순위·메모·결과는 다른 탭에 따로 쌓입니다.
그래서 다음에 엑셀을 새로 받아 이 탭만 갈아끼워도 적어 둔 것이 그대로 남습니다.

### 원본을 딴 파일에 두고 싶으면 (권하는 쪽)

즐겨찾기는 9월 내내 바뀝니다. 그때마다 상담 기록이 여덟 탭이나 같이 든 파일에서
탭을 지우고 붙여 넣는 것은 아무래도 위험합니다. **원본만 딴 파일에 두면** 새 엑셀을
받았을 때 그 파일만 갈아끼우면 되고, 상담 기록이 든 시트는 건드릴 일이 없습니다.

1. 즐겨찾기 엑셀은 **그 자체로** 구글 시트로 올립니다 (여기에는 Apps Script 를 붙이지 않습니다)
2. 주소창의 주소를 복사합니다
3. 보드가 붙어 있는 시트의 `설정` 탭 **B2** 칸에 그 주소를 붙여 넣습니다

이렇게 두면 보드 위에 「즐겨찾기 원본을 〈파일 이름〉에서 읽었습니다」라고 뜹니다.
**못 열면 그것도 붉게 알립니다** — 조용히 옛 자료를 읽는 일은 없습니다.

다음에 엑셀을 새로 받으면 그 파일의 원본 탭만 갈아끼우거나, 새 파일을 올리고
`설정` B2 의 주소만 바꾸면 됩니다.

> 어느 쪽이든 **순위·메모·결과는 안 날아갑니다.** 학번+대학+전형+학과로 만든
> 안정키로 붙어 있어서, 원본이 통째로 바뀌어도 같은 지원에는 그대로 다시 붙습니다.

---

## 2. Apps Script 붙이기

1. 그 시트에서 **확장 프로그램 → Apps Script**
2. 열린 편집기의 `Code.gs` 내용을 **모두 지우고**,
   이 저장소의 [`board/apps-script/Code.gs`](apps-script/Code.gs) 를 통째로 붙여 넣기
3. 저장 (Ctrl+S)

---

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → **웹 앱**
3. 이렇게 고릅니다

   | | |
   |---|---|
   | 설명 | 수시 상담 보드 |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   > 「모든 사용자」가 맞습니다. 학생이 자기 링크로 들어와야 하는데, 학생은 학교
   > 계정으로 로그인한 상태가 아닐 수 있기 때문입니다.
   > 대신 학생 링크에는 **그 학생만 여는 열쇠**가 붙어 있어 남의 것은 열리지 않습니다.

4. **배포**를 누르면 권한을 묻습니다. 「고급 → 안전하지 않은 페이지로 이동」을 거쳐
   허용해 주세요. 본인이 만든 스크립트라 뜨는 안내입니다.
5. 나오는 **웹 앱 URL**(`…/exec` 로 끝나는 것)을 복사해 둡니다.

---

## 4. 보드 열기

<https://maechorom31-pixel.github.io/univ/board.html>

1. 오른쪽 위 **설정**
2. 3번에서 복사한 주소를 넣고 **저장하고 연결**

**한 번만 넣으면 됩니다.** 그 브라우저가 기억합니다(`localStorage`). 다음부터는
보드 주소만 열면 바로 뜹니다.

다만 **브라우저마다 한 번씩**입니다 — 학교 컴퓨터·집 컴퓨터·휴대폰이 각각입니다.
시크릿 창이나 브라우저 자료를 지우면 다시 넣어야 합니다. 이건 일부러 이렇게 둔
것입니다. 배포 주소가 사실상 열쇠라서, 서버에 두거나 링크에 실어 두면
주소 한 줄이 새는 순간 3학년 전체 자료가 새기 때문입니다.

먼저 화면만 보고 싶으시면 **「보기용 자료로 열기」**를 누르세요.
지어낸 이름으로 모든 화면이 돌아갑니다.

---

## 5. 학생 링크 나눠 주기

**학생 링크** 화면 → 반을 고르고 **링크 만들기**.

- 이미 만든 학생은 그대로 두고 없는 학생만 새로 만듭니다.
- **CSV 복사** 는 반 명단에 붙여 문자로 발송할 때
- **문자 문구 복사** 는 이름과 주소가 든 완성 문장이라 그대로 붙여 넣으면 됩니다

> 링크 하나는 그 학생의 지원만 엽니다. **본인에게만** 보내 주세요.

## 시트에 생기는 탭

보드가 알아서 만듭니다. 손으로 만들지 않으셔도 됩니다.

| 탭 | 무엇이 쌓이나 |
|---|---|
| `배치` | 6칸 순위·후보·보관 |
| `메모` | 상담 메모 (`visible=Y` 면 학생 화면에도 보임) |
| `결과` | 1단계·최종·예비번호·등록 |
| `일정` | 면접·실기·모의면접 날짜 |
| `별칭` | 이름이 달라 안 붙던 학과를 손으로 이어 준 것 |
| `공유` | 학생별 링크 열쇠 |
| `기록` | 누가 언제 무엇을 바꿨나 |
| `설정` | (선택) 쓸 수 있는 계정 제한 · **B2 에 원본 시트 주소** |

### 계정을 제한하고 싶으면

`설정` 탭 A열에 쓸 수 있는 구글 계정 이메일을 한 줄에 하나씩 적습니다.
**한 줄이라도 적히는 순간부터** 그 명단만 들어올 수 있습니다.
비워 두면 주소를 아는 사람은 모두 들어옵니다.

## 코드를 고친 뒤에는

**Apps Script 코드를 고쳤으면 반드시 다시 배포해야 반영됩니다.**

> 배포 → **배포 관리** → 연필(수정) → 버전 **새 버전** → 배포

「새 배포」로 만들면 **주소가 바뀌어** 이미 나눠 준 학생 링크가 전부 죽습니다.
반드시 **배포 관리 → 수정**으로 기존 배포의 버전만 올려 주세요.

## 잘 안 될 때

| 증상 | 볼 곳 |
|---|---|
| 「연결 실패」 | 주소가 `…/exec` 로 끝나는지. `…/dev` 는 본인만 열립니다 |
| 「쓸 수 있는 계정이 아닙니다」 | `설정` 탭에 이메일이 적혀 있는지 |
| 학생이 0명으로 나온다 | 보드 위에 「어느 탭을 읽었다」는 안내가 뜹니다. 그 탭이 원본이 아니면 탭 이름을 `다운로드 원본`·`원본`·`즐겨찾기` 중 하나로 바꿔 주세요 |
| 「원본 시트를 열지 못했습니다」 | `설정` B2 의 주소를 확인해 주세요. 그 파일이 같은 계정 것이어야 합니다 |
| 지원이 전부 「자료 없음」 | 즐겨찾기의 `학교유형` 칸을 봐 주세요. 보드는 「일반대」·「전문대」·「특수대」를 알아보고, 모르는 말이면 두 자료를 다 뒤집니다 |
| 학생이 「잘못된 주소」 | 링크를 다시 만들어 주세요. 열쇠가 바뀌면 옛 링크는 죽습니다 |
| 값이 안 붙는 학과가 많다 | **점검** 화면에서 이어 주세요. 한 번 이으면 그 학과의 모든 학생에게 붙습니다 |
| 고친 게 반영이 안 된다 | 위의 **다시 배포** |

## 만드는 사람을 위한 메모

시험 돌리기

```
node board/parse.test.mjs      # 엑셀 파서
node board/match.test.mjs      # 이름 맞추기
node board/stats.test.mjs      # 결과 통계
```

`parse.test.mjs` 와 `match.test.mjs` 는 실제 즐겨찾기 파일을 넘기면 훨씬 많은 것을
확인합니다. **그 파일은 저장소에 넣지 않습니다** (학생 이름이 들어 있습니다).

```
node board/parse.test.mjs /경로/즐겨찾기.xlsx
node board/match.test.mjs /경로/즐겨찾기.xlsx
```

전형일정 자료 다시 만들기 (PDF 가 갱신되면)

```
python3 scripts/build_schedule.py <pdf들...> -o data/schedule2027.json
```

파트별 계약과 지켜야 할 것은 [`CONTRACT.md`](CONTRACT.md) 에 있습니다.

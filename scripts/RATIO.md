# 수시 경쟁률 통합 — 쓰는 법

## 배포 주소

https://maechorom31-pixel.github.io/univ/ratio.html

브랜치에 `ratio.html`을 푸시하면 자동으로 갱신됩니다.

## 선생님 PC에서 한 번에 돌리기

윈도우는 저장소 폴더의 `경쟁률수집.bat`을 더블클릭합니다.
맥은 터미널에서 `sh 경쟁률수집.command`.

## 명령으로 돌리기

    python scripts/ratio_fetch.py     # 지금 시각 기준으로 수집 -> data/ratio/snap-*.json
    python scripts/ratio_build.py     # 스냅샷 + 과거 자료 -> ratio.html

`ratio.html`을 브라우저로 열면 끝입니다. 인터넷 연결 없이도 열립니다.

## 진학어플라이

`addon.jinhakapply.com`은 데이터센터 IP를 막고 있어 클라우드에서는 403이 납니다.
개인 PC·학교망에서 같은 명령을 돌리면 함께 수집됩니다. 실패한 곳은 건너뛰고
화면의 「대학별 기준시각」 탭 아래에 목록으로 남습니다.

## 대학 추가

`scripts/ratio_sources.json`에 주소를 넣습니다.

- 유웨이: 작년(2026학년도) 주소를 그대로 넣어도 됩니다. 학년도 문자를 바꿔
  올해 주소를 만들어 씁니다.
- 진학어플라이: `Ratio<코드>.html`의 코드 8자리만 넣습니다.

## 자료 출처

- `data/ratio_hist.json` — 2025·2024·2023학년도 시점별 경쟁률(3일 전 ~ 최종).
  배율 통계를 여기서 뽑습니다.
- `data/mojip2027.json` — 2026·2025·2024학년도 최종 경쟁률. 「작년 최종」과
  「진도율」이 여기서 나옵니다.

## 시점을 자주 남기면 좋은 이유

지금 남기는 스냅샷이 내년에는 2027학년도 시점별 자료가 됩니다.
마감 전날·당일에 촘촘히 돌려 두면 내년 예측의 근거가 그만큼 두꺼워집니다.
